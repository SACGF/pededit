# claude/ — agent notes

Planning and research documents. Nothing here is loaded automatically; read
what you need.

- `overall_plan.md` — the phase plan. Status summary lives in the root
  AGENTS.md; update both when a phase moves.
- `layout_engine_guide.md` — required reading before touching the layout
  engine or renderer.
- `search_report.md` — survey of 60+ existing pedigree tools with a feature
  gap analysis in three tiers (open source table stakes, commercial only,
  nobody does it).
- `phase_6_*.md`, `phase_7_*.md`, `export_u_plan.md` — per-feature design
  notes written before implementation. Write a new one for any feature that
  needs more than a paragraph of design.
User research, outreach plans and paper drafts are **not** here. They live in
the private repo `SACGF/pededit_private` (usually checked out as a sibling
directory `../pededit_private`). Do not copy material from there into this
public repo.
